# Phase 3B — Saudi library POC ingestion investigation

Checked 2026-10-21. **Public video ingestion is technically possible through normally exposed HTTPS MP4 URLs. A lawful basis for storing copies/deriving landmarks or training/distributing a model has not been established. No video dataset was downloaded; no library landmarks, tensors or trained model were produced.** Ordinary browser playback/preload was used for observation, not exported as a corpus.

The latest task authorized a conditional minimal research POC. It did not supply rightsholder permission. Absence of a website sentence specifically banning AI does not establish lawful copying. This report distinguishes technical feasibility, website policy, legal basis and scientific validity rather than treating them as one gate.

## Method and boundaries

- Inspected only the existing **25 candidate records**, public policy pages, robots.txt, sitemap.xml and the same public JSON term route observed in normal page loading. No 8,818-record enumeration, guessed IDs, private endpoint, authentication workaround, anti-bot bypass or certificate-validation bypass.
- Public page observations used the normal browser. The observed-resource inventory recorded URLs already requested by that page. Exact metadata API records were read only for those 25 known IDs; no write/analytics endpoints were replayed.
- Five ordinary bounded HTTPS text requests checked raw HTML/text response status and structure. An initial local sandbox SSL/keylog permission error was resolved by running the read-only request outside that sandbox, retaining default HTTPS verification; it was not a server access-control rejection.
- All 25 normal player previews were visually inspected. Face/upper body/hand notes refer to a **single public preview state**, not full-motion annotation, landmark completeness or lexical one/two-hand classification. No identity recognition, face embeddings, named identities or invented signer IDs were used.

## HTML, source and normal requests

Sample record [شكراً #5018](https://sshi.sa/category/14/5018): raw response **HTTP 200, text/html, 1,357 bytes**, a client-rendered shell with script `/r1/index-Cnwd3sao.js`. There is no raw `<video>` or JSON-LD payload in that HTML. After rendering, the DOM contains a primary `<video>` whose `src` points at `/api/file/<percent-encoded filename>.mp4`, `preload="metadata"`, inline/loop attributes and no DRM/encrypted-player mechanism observed. No `rel=canonical` tag was found in the inspected rendered records; the official route/share permalink is used as the canonical record reference here.

Public JSON fields on all 25 inspected records: `id`, `wordAr`, `wordEn`, `category_id`, **one string `video`**, `description`, `synonym`, `descriptionImage`, `like`, `dislike`, `watchCount`, `created_at`, `updated_at`, nested `category`. **No signer, session, take, repetitions, FPS or capture-date fields were exposed.** Database creation/update timestamps are not recording-session labels; viewing can update counters/timestamps. Some synonyms contain the literal string `"null"`; do not treat it as a real alias. Filenames can differ from titles (أريد → أراد.mp4), so never construct the media path from a guessed normalized title.

## Robots, sitemap and policies

- [robots.txt](https://sshi.sa/robots.txt): HTTP 200 text/plain, `User-agent: *` with empty `Disallow`. No sitemap directive. This is crawl guidance, **not copyright/ML permission**.
- [sitemap.xml](https://sshi.sa/sitemap.xml): HTTP 200 **text/html**, the same 1,357-byte SPA shell, rendered as the site's not-found page. No XML sitemap was obtained. Do not report its HTTP 200 as a valid sitemap.
- [Privacy](https://sshi.sa/privacy): general lawful-use, confidentiality and non-interference conditions; no explicit ML grant and no specific AI-research ban found. Lawful-use language still requires an actual lawful basis.
- [Rules](https://sshi.sa/rules): interpreter professional conduct, not a dataset license.
- Library footer reserves copyright to the Association. No public dataset/API/ML/model-distribution license was found. These internal public API routes have **no discovered developer agreement/service guarantee**.
- [SAIP's official Copyright Law PDF, Article 15(1)](https://externalportal-backend-production.saip.gov.sa/sites/default/files/2022-06/copyright%20law%201.pdf) excludes audiovisual works from the general personal-copying exception. Article 15 lists limited other uses; applicability to MAEEN video-copying/ML processing was not established. [Official copyright guidance](https://www.saip.gov.sa/en/resources/ip-information/digital-guide/ip-category/copyrights) also describes author control over audiovisual uses. This is an identified rights uncertainty, not a claim that every research act is unlawful or a legal opinion resolving all exceptions.

**Decision:** normal public inspection and metadata dry run completed; no stored-video/landmark POC under an unverified exception. Obtain Association permission (a narrowly scoped one-clip engineering grant is enough to unblock that separate test) or a qualified review establishing a specific applicable lawful basis. Rights for fitting, weights, public web use and commercial use remain separate. [Arabic request](PERMISSION_REQUEST_AR.md) now includes a one-clip engineering option; it has not been sent.

## Samples, signers and scientific validity

**Observed:** one exposed main clip per selected record; no repeated-take list or alternate video array. **Not established:** that no other takes exist in Association archives or elsewhere in the library. Prior duplicate titles outside this fixed shortlist do not count as independently recorded repetitions and were not added to this POC.

Different presenter appearances are visible across these terms. **Unique signer count is unknown**, no identity matching was performed, and no per-class signer variation is established. A varied cast across different classes does not provide multiple signers *for each class*; class and performer may be confounded. Body/clothing similarity also cannot establish a session identity.

With one clip per class, a class-complete train/validation/test split is impossible even before requiring signer separation. Splitting frames/windows/crops of the same source file is leakage, not generalization. Repeated playback, snapshots, speed changes, mirroring and sentence concatenation do not create independent samples. The 86.96 seconds could support a **licensed engineering pipeline check or exemplar reference**, not a defensible supervised 25-class recognition benchmark or live-recognition accuracy claim.

**Proof-of-concept supervised training scientifically defensible now: NO.** It might demonstrate memorization/overfitting, which is not the requested recognition result; no optimizer step was run. No Sign/out-of-vocabulary negatives and independent validation streams are also absent. Neither signer-independent nor source-independent metrics can legitimately be reported.

## Executed workflow and what remains

Implemented [metadata-only dry run](training/maeen_data/library_poc.py): validates exactly the frozen 25 IDs, official page/category/media provenance, finite loaded duration/dimensions, and the current one-reference-per-record observation. It rejects expanded/duplicated records, arbitrary hosts/path traversal and malformed metadata. It never converts robots permission or claimed JSON rights into download/training permission. It has no network client, media read/copy, detector invocation, tensor construction or fitting code.

```powershell
# From training/: observation audit only; does not acquire videos
.\.venv\Scripts\python.exe -m maeen_data.library_poc --observations ../docs/phase3/official-library-poc-observations.json --output ../docs/phase3/official-library-poc-plan.json
```

Run result: **25 records checked, 0 downloaded videos, 0 extracted landmark sequences, 0 library tensors, 0 training runs**. The plan's `[1,32,268]` is the **expected existing feature contract**, not a produced tensor. Existing artificial geometry/blank-decoder tests do not become evidence of successful library extraction.

After a lawful basis is reviewed, the minimum *engineering-only* subset is **one clip: شكراً #5018 (3.72s)**. Store privately/ignored, hash original bytes, preserve actual dimensions/timestamps and use the existing hand/pose/face extractor. Inspect separate left/right presence, shoulders, face masks, drops, gaps, motion preservation and real handedness. Run the actual shared TypeScript `prepareSequence`, measure acceptance/coverage and emit a private float32 tensor only if validation succeeds. No invented signer is required for an engineering decoder check; it must remain outside training partitions. A one-handed clip cannot validate two-hand tracking: a second specifically authorized two-hand sample, e.g. #11081, would be justified only for that additional check.

The production `prepare-word-features` and training CLIs intentionally retain source/consent guards. Do not relabel library material first-party to force extraction/normalization. Existing authorized-library staging also requires real provider signer/session metadata before a training corpus can be admitted. A future approved engineering runner needs its own narrow grant gate and shared-normalizer handoff; **it was not executed or falsely claimed complete here**.

## Exact blockers and next evidence needed

1. **Rights:** no reviewed license/exception for storing video and deriving landmarks; fitting/model-distribution/public/commercial scopes remain unconfirmed.
2. **Samples:** only one exposed reference per selected class; obtain original independent repeated takes per class, not copies/windows.
3. **Signer coverage:** provider anonymous signer IDs and sessions/takes, with class coverage in separate train/validation/test signer sets. Request archives/additional licensed recordings; do not infer IDs from appearance or database timestamps.
4. **Negative data:** licensed original No Sign/out-of-vocabulary footage and continuous validation streams.
5. **Real extraction:** no library landmark coverage/normalizer success, native/browser detector parity, dynamic handedness or end-to-end latency measured yet.

Word UI stays **Not Implemented / Data Access Required**, supported words **0**, no app redesign, no word weights/inference, nothing deployed. First-party plans/assets and existing model files are preserved.
